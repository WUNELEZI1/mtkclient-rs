## DA Stage2 通信协议（自学总结）

### 启动握手
- **设备发送**: 0xB1B2B3B4
- **主机回应**: 0xF00DD00D + 命令码

### 完整命令表
| 命令 | 功能 | 发送 | 响应 |
|------|------|------|------|
| 0x6000 | 初始化 eMMC | F00DD00D + 6000 | D1D1D1D1 |
| 0x1000 | 读块 | F00DD00D + 1000 + block号 | 512字节数据 |
| 0x1001 | 写块 | F00DD00D + 1001 + block号 + 512字节数据 | D0D0D0D0 |
| 0x1002 | 切换分区 | F00DD00D + 1002 + 分区号 | 无 |
| 0x2000 | 读 RPMB | F00DD00D + 2000 + 地址 | 256字节数据 |
| 0x2001 | 写 RPMB | F00DD00D + 2001 + 256字节数据 | 无 |
| 0x3000 | 重启设备 | F00DD00D + 3000 | 无 |
| 0x3001 | 踢 watchdog | F00DD00D + 3001 | 无 |
| 0x4000 | 写内存 | F00DD00D + 4000 + 地址 + 数据 | D0D0D0D0 |
| 0x4002 | 读内存 | F00DD00D + 4002 + 地址 + 大小 | 内存数据 |
| 0x5000 | 禁用缓存和 SMP | F00DD00D + 5000 | D0D0D0D0 |

### 数据传输协议
1. **4字节数据传输**:
   - 使用 `send_dword` 和 `recv_dword` 函数
   - 数据需要进行字节序转换（大端转小端）

2. **块数据传输**:
   - 读块：使用 `usbdl_put_data` 发送 512 字节数据
   - 写块：使用 `usbdl_get_data` 接收 512 字节数据

3. **内存操作**:
   - 读内存：指定地址和大小，返回内存数据
   - 写内存：指定地址和数据，支持不同数据长度（1/2/4 字节）

### eMMC 操作
1. **块大小**: 固定为 512 字节
2. **分区支持**:
   - user 分区：主存储分区
   - boot1/boot2：启动分区
   - rpmb：安全分区
   - gp1-gp4：通用分区

3. **RPMB 操作**:
   - 支持读写操作
   - 需要 MAC 验证
   - 支持写计数器

### 错误处理
- **非致命错误**: DA 会继续执行，输出错误信息
- **致命错误**: DA 会退出命令循环
- **超时处理**: 对于需要等待的操作，有超时机制

### 特殊功能
1. **设备重启**:
   - 写入特定寄存器实现设备重启

2. **Watchdog 控制**:
   - 支持踢 watchdog 操作，防止设备重启

3. **缓存控制**:
   - 支持禁用指令缓存和 SMP

### 通信流程
1. **启动**:
   - DA 启动后发送 0xB1B2B3B4 握手信号
   - 主机发送 0xF00DD00D + 命令码

2. **eMMC 初始化**:
   - 发送 0x6000 命令
   - 接收 D1D1D1D1 响应

3. **数据操作**:
   - 根据需要发送读/写命令
   - 传输数据

4. **结束**:
   - 可以发送 0x3000 命令重启设备
   - 或保持连接等待后续命令
